# 🛠️ Geliştirme Görevleri (Final Task List) - Micro Factory AI (DAN)

- [x] Proje klasör yapısının (index.html, style.css, script.js) ve Tailwind CSS bağlantısının kurulması.
- [x] **Premium SaaS Tasarımı:** Modern Glassmorphism UI ve Indigo-Violet renk paletinin uygulanması.

- [x] **Görsel Takip Sistemi:** Canlı KPI panelleri, count-up animasyonları ve sipariş statüsünü gösteren interaktif Timeline barı.

### ⚙️ Phase 2: Veri Mimarisi ve Lojistik Motoru
- [x] **Kurumsal Hub Ağı:** Şahıs isimlerinden arındırılmış, 7 bölgeye yayılmış "Bölgesel Kooperatif Hub" veritabanının (JSON) inşası.
- [x] **Smart Routing Algoritması:** Karbon emisyonunu minimize eden, teslimat noktasına en yakın Hub'ı önceliklendiren lojistik motoru.
- [x] **Milk-Run & Yeşil Lojistik:** 50 adet altı siparişlerin lojistik emisyonunu sıfırlamak için **24 Saat Günlük Milk-Run Havuzu** ile konsolide edilmesi.
- [x] **V16 Veri Kalıcılığı:** `localStorage` mimarisinde "0" (sıfır) değerlerinin hatalı algılanmasını önleyen (Strict Null Logic) kalıcı veri yönetimi.

### 🧠 Phase 3: AI ve Omni-Channel İletişim Katmanı
- [x] Google Gemini 2.5 Flash API entegrasyonu ve kurumsal karar motoru (System Prompt) mimarisi.
- [x] **Zırhlı Semantik Filtre:** Ağır sanayi (Aks, motor, beton vb.) ve metal işçiliği/hırdavat (Vida, çivi, somun vb.) taleplerini otonom reddeden güvenlik katmanı.
- [x] **Kati Reçete Denetimi:** Üretim hatasını sıfırlamak için Renk, Beden, Gramaj veya Ölçü bilgilerini (Örn: 35x45cm) zorunlu kılan akıllı denetçi.
